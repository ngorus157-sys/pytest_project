# Практическая работа: Тестирование кода с помощью pytest

Репозиторий содержит материалы практической работы по автоматизированному тестированию кода на Python с использованием фреймворка **pytest**. В ходе работы изучены основы написания тестов, обработка ошибок, использование фикстур, параметризация тестов и работа с исключениями.

---

##  Структура проекта

```text
pytest_project/
├── .pytest_cache/        # Системный кэш pytest (создается автоматически)
├── __pycache__/          # Скомпилированный кэш Python-файлов (создается автоматически)
├── venv/                 # Локальное виртуальное окружение Python
├── functions.py          # Исходный код с тестируемыми функциями и классами
├── pytest.ini            # Файл конфигурации для регистрации кастомных маркеров
├── requirements.txt      # Список зависимостей проекта
└── test_functions.py     # Тесты pytest для проверки работоспособности кода
```

---

##  Быстрый старт

### 1. Активация виртуального окружения (venv)
Перед началом работы обязательно активируйте виртуальное окружение:

* **На Windows (в Command Prompt / cmd):**
  ```cmd
  venv\Scripts\activate.bat
  ```
* **На Windows (в PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
* **На macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 2. Установка зависимостей
Установите все необходимые для работы библиотеки (включая `pytest`) из файла зависимостей внутрь активированного окружения:
```bash
pip install -r requirements.txt
```

### 3. Запуск тестов
Для запуска всех тестов выполните команду:
```bash
pytest
```

Для получения подробного и развернутого отчета по каждому тест-кейсу используйте флаг `-v`:
```bash
pytest -v
```

### 4. Выборочный запуск тестов по маркерам
В проекте настроены маркеры для разделения тестов по категориям через файл `pytest.ini`. Вы можете запускать их отдельно:
```bash
# Запустить только математические тесты
pytest -m math

# Запустить только тесты профиля пользователя
pytest -m user_profile
```

##  Обзор выполненных самостоятельных заданий

В рамках практической работы были реализованы тесты для 5 различных сценариев:

### [Задача 1] Простая валидация пароля
* **Что тестируется:** Функция `is_valid_password(password)`.
* **Покрытие:** Проверены три базовых сценария: корректный пароль (>8 символов), слишком короткий пароль (<8 символов) и пограничное значение длины (ровно 8 символов).

### [Задача 2] Определение возрастной группы (Параметризация)
* **Что тестируется:** Функция `get_age_group(age)`.
* **Покрытие:** Написан один компактный параметризованный тест с использованием декоратора `@pytest.mark.parametrize`. Особое внимание уделено проверке жестких граничных стыков возраста: 12, 13, 17 и 18 лет.

### [Задача 3] Расчет стоимости корзины (Фикстуры)
* **Что тестируется:** Функция `calculate_cart_total(cart_items)`.
* **Покрытие:** Реализована фикстура `@pytest.fixture`, подготавливающая тестовый набор данных корзины с товарами. На основе одной фикстуры написаны тесты для подсчета общей стоимости и валидации состава корзины.

### [Задача 4] Доступ к элементу словаря (Тестирование исключений)
* **Что тестируется:** Функция `get_value_from_dict(data_dict, key)`.
* **Покрытие:** Реализован тест для успешного извлечения данных по существующему ключу, а также тест на перехват и валидацию исключения `KeyError` с помощью контекстного менеджера `with pytest.raises()` в случае отсутствия ключа.

### [Задача 5] Управление кошельком (Комплексный класс)
* **Что тестируется:** Логика поведения класса `Wallet` и кастомного исключения `InsufficientFundsError`.
* **Покрытие:** 
  * Фикстура для инициализации кошелька с начальным балансом.
  * Тесты успешного пополнения (`deposit`) и снятия (`withdraw`) денежных средств.
  * Тест на вызов ошибки `InsufficientFundsError` при попытке овердрафта.
  * Параметризованный тест, проверяющий генерацию `ValueError` при передаче некорректных (нулевых или отрицательных) значений во все методы класса.
